# Arte desta versão

O mapa `assets/jardim-descobertas.png` foi gerado originalmente para este projeto com a ferramenta integrada de geração de imagens (image_gen), em 2 de novembro de 2026. Não foi usada a alternativa por API/CLI. A imagem foi incorporada sem alteração. Ícones de interface e companheiros usam emojis do sistema; a aparência varia por plataforma. O ícone solar SVG é provisório e não substitui a logo oficial.

## Atualização V3

A logo oficial enviada pelo usuário foi incorporada sem alteração em `assets/logo-oficial.png`; a marca Kids aparece como texto de interface. O favicon solar antigo permanece como ícone de navegador, não como substituto da marca.

O Vale (`assets/vale-descobertas.png`) é uma imagem gerada para esta expansão, com o jardim anterior como referência de estilo: fazendinha com celeiro à esquerda, escola no alto à direita, casa de jogos embaixo à direita, caminhos e riacho central, estética de diorama infantil, sem texto. Prédios clicáveis são controles HTML sobre a imagem.

Personagens humanos são SVG locais; itens trocam cores e acrescentam chapéu ou mochila. Animais, pets e objetos usam emojis do sistema, com movimentos CSS simples. Bandeiras e fontes constam em GEOGRAFIA.md.
